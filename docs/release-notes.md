# v0.6.0

- 新检测无需选择用户 Key，使用配套宿主的管理员账号诊断通道；旧历史任务保留原 Key 权限和计费。
- 新增默认关闭、手动选择账号的持久化定时短请求，串行执行；失败或结果未知即暂停，不补发、不自动重试。
- 保留 RPC v5、原上游 SDK、Meow / ModelTrace 引擎和历史数据。需要 Const-Time/codex-proxy-rs 3.14.0 或更高版本，包含 host.account.probe 扩展。
- 诊断会消耗真实上游额度；额度窗口是否开始计时由上游决定，成功不能保证账号没有风控。

# v0.5.0

- 升级 RPC v5，使用固定的上游 SDK；需搭配支持 RPC v5 的宿主。
- 适配原始 HTTP 字节头和 WebSocket 模型事件。
- 保留已有检测记录、后台任务、取消和资源保护。
- 插件上游目前无待合并提交。

# v0.4.0

- 升级到上游插件 RPC v4，适配宿主 3.13.0；旧 v2 宿主请使用 v0.3.0。
- 保留检测历史与状态 schema，升级已有实例不需要删除历史。
- 打包验收覆盖 v4 分段帧、Meow / ModelTrace、暂停恢复及历史回读。

# v0.3.0

- 配套宿主支持后台续调 v1 时，由宿主串行执行检测；切换菜单或关闭浏览器不停止检测。
- 失败即暂停，手动继续；不自动重试错误或结果未知的收费请求，尝试预算及历史保留。
- 暂停/结束保留当前题结果；宿主重启、插件停用或版本切换后需手动续测。
- 不兼容的宿主在开始前明确拒绝，不降级为隐蔽的页面循环。
- 增加提交检查、离线安装包测试和版本标签发布流水线。

必须先升级到 Const-Time/codex-proxy-rs v3.12.4 或更高且支持后台续调 v1 的宿主；仅升级插件不能修复旧宿主的 30 秒调用限制。后台运行不保证上游请求、解析或评分一定成功。

保留上游及第三方署名，完整插件仍按 PolyForm Noncommercial 1.0.0 分发。
