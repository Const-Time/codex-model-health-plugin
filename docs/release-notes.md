# v0.10.0

- 定时检测新增「并行账号数」1–3：不同账号可同时请求，同一账号逐题串行；新计划默认 2，旧计划保留 1，需手动调整并保存。
- 共用一个检测引擎，未完成任务优先继续；调低并行数不重置进度。某账号当前题失败最多额外重试 2 次，仍失败仅暂停该账号，其他账号继续生成各自报告。
- 升级 schedule 状态 v1/v2/v3 → v4，保留配置、总开关、暂停状态、检测进度和历史记录。请在原实例在线更新，不需要删除重装；迁移后不能直接降级覆盖旧插件。
- **并行功能需要主程序 v3.15.2 或更新版本。**兼容 v3.15.0/v3.15.1，旧宿主自动保持串行并显示提示。建议先升级主程序，再更新插件。
- 已通过 56 项后端测试、严格 Clippy、前端构建和浏览器配置保存验证；离线协议测试验证真实重叠请求、失败隔离、旧宿主降级和关闭计划暂停全部账号，不调用真实模型。

# v0.9.0

- 适配上游 RPC v7 的阶段预算及协作挂起/恢复，固定原始 SDK 为 `dd529d07`。
- 手动检测和定时任务支持停止调度的 OpenAI 账号，账号名称明确标识状态；检测不会重新启用正常请求调度。
- 保留 Meow / ModelTrace、Cron / 每日执行时间、时区、多选账号、每题最多 2 次额外重试及失败暂停逻辑。升级不改变计划总开关和暂停状态，不迁移或清空现有历史。
- **需要先升级 Const-Time/codex-proxy-rs 至 3.15.0，再在原实例切换插件包。**旧 RPC v5 宿主不兼容；诊断仍消耗真实上游额度，不扣用户 Key 额度。

# v0.8.0

- 定时任务新增 Meow / ModelTrace 检测方法，支持 Meow 对照基线和档位，完整执行后保存模型指纹报告；保留短探测选项、账号多选、Cron、每日指定时间和时区。
- 当前题失败最多额外重试 2 次，第三次失败暂停对应账号；成功题不重跑，模型不匹配属于有效结果。关闭页面仍串行执行，每轮后台调度最多推进一道题。
- 检测进度与失败次数持久化，中断请求计入重试次数；显式恢复沿用历史中配置一致的任务进度。可从计划账号或检测历史查看报告和请求明细。
- schedule 状态 v1/v2 → v3、runs 状态 v1 → v2；保留旧计划的短探测模式、时间与暂停状态，不自动扩大检测范围。历史最多 16 条，不能直接降级到旧状态版本。
- **先升级 Const-Time/codex-proxy-rs 至 3.14.2，再在原实例切换此插件制品。**完整定时检测依赖新增宿主能力和 90 秒单题时限；不需要选择用户 Key，不扣用户 Key 额度，仍消耗真实上游额度。
- 本地通过 50 项后端测试、8 项前端测试、浏览器回归和严格 Clippy；离线模拟验证 Meow 36/36、ModelTrace 3/3、重试暂停与恢复。发布流水线继续验收实际安装包。

# v0.7.0

- 定时账号探测支持按间隔、每天指定时间和五段 Cron 表达式，可选择并保存 IANA 时区。
- 新增后续三次执行时刻预览与服务端校验；预览不调用模型、不修改计划。
- 账号选择改为可搜索多选（最多 50 个），表单统一使用系统组件；检测与定时探测均支持模型下拉搜索和自定义模型。
- 移除免 Key 检测遗留的测试 Key 提示；保留串行调用、失败暂停、显式恢复和未决请求保护。
- 升级自动迁移插件私有 schedule 状态 v1 → v2，保留旧账号、间隔、下次执行时间及暂停/未决状态；检测历史不变。迁移后不支持直接降级到旧插件。
- 多账号到点后逐个执行，受宿主维护周期和排队影响；服务恢复后每个到期账号最多执行一次，不逐次补发历史周期。
- 需要 Const-Time/codex-proxy-rs >=3.14.0、<4.0.0。本次无需更新主程序；请在原插件实例切换制品。
- 已完成 42 项后端测试、8 项前端测试及浏览器回归；发布流水线继续验证实际安装包。

# v0.6.0
