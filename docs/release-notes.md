# v0.3.0

- 配套宿主支持后台续调 v1 时，由宿主串行执行检测；切换菜单或关闭浏览器不停止检测。
- 失败即暂停，手动继续；不自动重试错误或结果未知的收费请求，尝试预算及历史保留。
- 暂停/结束保留当前题结果；宿主重启、插件停用或版本切换后需手动续测。
- 不兼容的宿主在开始前明确拒绝，不降级为隐蔽的页面循环。
- 增加提交检查、离线安装包测试和版本标签发布流水线。

必须先升级到 Const-Time/codex-proxy-rs v3.12.4 或更高且支持后台续调 v1 的宿主；仅升级插件不能修复旧宿主的 30 秒调用限制。后台运行不保证上游请求、解析或评分一定成功。

保留上游及第三方署名，完整插件仍按 PolyForm Noncommercial 1.0.0 分发。
