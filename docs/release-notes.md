# v0.11.0

- 手动检测与定时检测的请求模型新增 `gpt-6.1-sol`、`gpt-6.1-terra`，仍支持自定义模型。
- Meow 升级到上游 dc608d5，使用新版 4.5.4-predictive.20261003.1 efficient 基线；快速/标准/完整档改为 32/64/128 题，新增 6.1 Sol 候选。区分 Sol 与 Astra 建议使用完整档。
- ModelTrace 升级到上游 6cd4a8f，候选库由 17 增至 18，加入 Claude Haiku 5.5。
- 6.1 Terra 暂无上游专属检测基线，界面明确提示；选择请求模型不代表已有对应身份基线。
- 保留已保存的定时配置、并行数、暂停状态和历史报告；旧 Meow/ModelTrace 任务仍使用创建时的基线续跑，不重新评分历史结果。仅旧基线包含的已保存候选继续使用旧基线。
- RPC v7、插件 ID 和私有状态 schema 不变；请在原实例在线更新，无需删除重装。兼容宿主 >=3.15.0、<4.0.0，并行检测需要 >=3.15.2；建议使用配套 v3.16.0。
- 已通过 18 项检测引擎测试、10 项前端测试、56 项 Rust/跨进程测试、安装包 Meow 32 题和 ModelTrace 3 轮离线验收，以及多账号、cron/每日时刻、配置恢复、深浅色和移动端浏览器回归。测试不调用真实模型。
